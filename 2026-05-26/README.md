[ 3교시 ]
- LLM : 텍스트 입력에 따라 판단, 도구선택, 반복결정의 주체 (뇌 역할)
- Generator : 반복적으로 필요할 때만 데이터 생성(출력)하는 구조
- 일반함수는 return(호출한 곳으로 되돌린다 = 함수 종료) 사용, Generator는 yield(값 하나 내보내고 멈추기 =함수 종료X, 다음 호출 대기)
  ```
  # 예시( 함수 아님 )  
def simple_generator():
	print('첫번째')
	yield 1
	print('첫번째')
	yield 2
	print('첫번째')
	yield 3

  sample_gen = simple_generator() # 위 함수 호출처럼 보이지만, Generator 오브젝트 생성한 것(객체의 참조 선언)
                                # 객체의 참조로부터 값을 하나씩 받을 수 있는 것
next(sample_gen)       # 출력값 1
next(sample_gen)       # 출력값 2
next(sample_gen)       # 출력값 3
  ```

[ 4교시 ]
```
def iterator_generator(n):
	for i in range(n):
		print(i)
		yield i

it_gen = iterator_generator(3) # 3번 호출할 수 있는 함수가 되는 것

next(it_gen)  # 0
next(it_gen)  # 1
next(it_gen)  # 2
```

- 비동기 함수 (Asynchronous Functions)
 * Thread : 가상의 CPU 역할을 하는 SW
 * CPU : 프로그램 코드 실행하는 디바이스, CPU는 한 번에 하나의 코드밖만 실행 가능 
 * 파이썬은 내부에서 쓰레드를 생성하여 코드를 실행하고 있음
- 동기 함수 : 쓰레드(Thread)가 코드를 실행할 때 함수를 호출하고 그 함수가 리턴 값을 내놓을 때까지 
                     아무것도 수행하지 않고 값만 기다리는 방식 = Block 상태로 대기
- 비동기 함수 : 쓰레드(Thread)가 비동기 함수를 실행하고 그 함수가 리턴할 때까지 기다리지 않고 다른 작업 수행 가능
                         그 리턴 값은 OS의 메시지 루프에서 기다림, 기다리다가 값이 리턴되면 OS가 쓰레드에게 넘겨줌

- await : 비동기로 선언된 함수의 리턴값을 OS 메시지 루프에서 끝까지 기다리게 하는 명령어 (호출하고 기다리기 O)
